- options: A) 默认不阻塞页面解析 B) 默认同步加载并执行会阻塞解析，defer 延迟到解析完执行，async 加载完立即执行 C) defer 和 async 完全一样 D) script 不能放 head

- stem: 什么是 CSS 盒模型？border-box 与 content-box 的区别及实践建议。
- keywords: content, padding, border, margin, box-sizing
- analysis: 盒模型由内容区 content、内边距 padding、边框 border、外边距 margin 组成。content-box（默认）width 只算内容区，实际占宽 = width + padding + border，布局易出错；border-box 的 width 包含 padding 与 border，所设即所得。实践：全局 * { box-sizing: border-box }，尺寸计算直观、配合响应式更稳。

## q_c019_15
- type: short
- kp: JavaScript 基础
- difficulty: medium
- score: 10
- stem: 解释 JavaScript 的事件循环（Event Loop）：同步任务、宏任务、微任务的执行顺序。
- keywords: 调用栈, 宏任务, 微任务, Promise, setTimeout
- analysis: 执行模型：同步代码在调用栈执行 → 遇到异步注册回调 → 调用栈清空后，先清空微任务队列（Promise.then、MutationObserver），再取一个宏任务（setTimeout/IO/事件）执行，之后再次清空微任务，循环往复。因此 Promise.then 比 setTimeout 先执行；理解顺序才能解释"定时器不精确"与回调执行时机。

## q_c019_19
- type: short
- kp: JavaScript 基础
- difficulty: hard
- score: 10
- stem: 【面试题】解释 var/let/const 的变量提升与暂时性死区，并用例子说明。
- keywords: 提升作用域, undefined, ReferenceError, TDZ, 块级
- analysis: var 声明提升到函数/全局作用域顶部且初始化为 undefined（声明前访问得 undefined）；let/const 也有提升但不初始化，声明前访问处于暂时性死区（TDZ）抛 ReferenceError。作用域差异：var 函数作用域（循环共享绑定导致定时器输出 3），let 块级作用域（每轮独立绑定输出 0 1 2）。const 声明即须初始化且不可重新赋值。
