## 一、业务定位与核心链路

面向**成人职业技术学习**的 AI 助教：用户说出目标（"我想做 Java 开发"/"做了 3 年测试想转型"），引擎经**语义召回**匹配课程与职业知识，生成**转型方案 / 学习路径 / 课程推荐**，配套技术题与面试题练习；课程私有题库为购课权益（未购课工具层拦截）。

**规划链路（无映射表、无图谱）**：
```
用户目标表述（"我想学 Java"）
→ Query Rewrite 消解指代（已有组件）
→ 双路语义召回（ES，BM25+向量+RRF，top 10~15 宽召回）
   ├─ course_intro 索引：候选课程
   └─ enterprise_knowledge 的 CAREER 条目：岗位要求/行情/转型建议
→ MCP 课程工具取详情（价格/课时/大纲——权威数据，防幻觉）
→ 规划智能体：LLM 依据自身知识 + 课程介绍直接组织课程序列与阶段目标
→ 转型方案卡（课程带引用溯源）→ 摸底测试 → 回流诊断
```

**动态编排（路由与编排合一）**：
- 路由 LLM 调用的 JSON 输出扩展 `stages` 字段：本轮该执行的环节（如 `["diagnose"]`、`["diagnose","exercise"]`、全环节）
- "帮我诊断学情" → 只跑诊断 + 结尾建议话术（"要不要出几道题检验一下？"），不再强塞练习卡
- "帮我全面分析并制定学习计划" → 全环节，保留完整闭环演示能力
- 护栏保留在编排层代码：状态机校验、单轮环节上限（≤3）、环节级失败降级
- LLM 现场出题失败/不相关 → 直接道歉话术 + 环节标记 degraded，无降级链

## 四、MD 语料格式规范（摄入契约，定稿后不再变更）

### 1. 课程文件 `课程/c{XXX}_{课程名}.md`
```markdown
---
courseId: c001
name: Java 编程入门：从零基础到能写项目
track: java-backend        # 课程所属内容板块（展示/检索过滤用）
level: 入门                # 入门 | 进阶 | 高级（仅展示与过滤，排序由 LLM 决定）
price: 299
hours: 42
kps: [JavaSE 基础, 开发环境, 面向对象]
roles: [Java 后端工程师]    # 1~2 个岗位，受控词表 = 第二节岗位目录
---
## 课程介绍
（300~500 字。**必须含"适合人群/目标岗位"段落**——这是语义召回命中率的决定因素。
整体作为一条 chunk 入 ES course_intro 索引）

## 课程大纲
- 第 1 章 开发环境搭建与 Hello World（3h）
- ……
（入 MySQL course_info.outline 字段）
```

### 2. 题库文件 `题库/c{XXX}_题库.md`
```markdown
---
courseId: c001
---
## q_c001_01
- type: choice          # choice | short
- kp: JavaSE 基础
- difficulty: easy      # easy | medium | hard
- score: 5
- stem: 关于 JVM 的描述，下列哪一项是正确的？
- options: A) … B) … C) … D) …
- answer: B
- analysis: JVM 是 Java 虚拟机……（choice 必填）
- keywords: 字节码, 解释执行, 跨平台   # short 题评分关键词，逗号分隔
```
- 每门课 20 题：约 **12 choice + 8 short**，short 中含 **3 道面试题**（kp 含「面试」，difficulty ≥ medium）
- id 规则 `q_{courseId}_{两位序号}`；short 题无 options/answer，**必须**有 keywords + analysis（参考答案要点）
- 答案正确性由 AI 语料生产保证（技术事实题无算错风险），可选抽检脚本兜底

### 3. 知识条目文件 `知识条目/{分类}_{主题}.md`
```markdown
---
kp: Java 后端工程师
category: SKILL        # SKILL 技能知识 | CAREER 岗位与转型 | POLICY 服务政策
source: 《2026 程序员薪酬与技能调研》
---
（正文 200~400 字/条，可含多个 `## ` 小节，每小节独立成 chunk 入 ES）
```
- **CAREER 条目 30 份**（每岗位一份：技能要求/学习周期/行情/转型路径建议）+ SKILL 条目（按课程 kp 展开，60~80 份）+ POLICY（服务政策，沿用）

### 4. 摄入流向
| MD 内容 | 目标存储 | 说明 |
|---|---|---|
| 课程 frontmatter + 大纲 | MySQL `course_info`（tutor_biz） | 业务系统主数据 |
| 题目块 | MySQL `question_bank`（tutor_biz） | answer/analysis 独立字段，`getQuestions` SQL 不查出 |
| 课程介绍节 | ES `course_intro` 索引（新建） | 目标→课程语义召回 |
| 知识条目小节 | ES `enterprise_knowledge`（重建） | 讲解检索 + CAREER 岗位召回 |

## 五、冷启动摸底测试

首次诊断：用户目标 → 双路召回（岗位 CAREER 条目 + 候选课程）→ 规划智能体按**候选课程的核心 kp** 出 3~5 道摸底题 → 作答 → 现有批改/`learning_record` 回流管道 → 摸底结果作为后续规划的已掌握/薄弱输入。复用出题-批改闭环，仅新增触发时机与卡片类型。
