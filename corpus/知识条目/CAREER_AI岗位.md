## 大模型应用工程师
技能主线：Python→大模型 API 与 Prompt→RAG→Agent 与 MCP→项目实战。后端/数据背景转型最快（3-6 个月），薪资 20-45K，当前溢价最高的方向。差异化竞争力：工程化能力（评测/可观测/成本治理）比模型知识更稀缺。
## AI 产品经理
技能主线：产品基本功→大模型能力边界（能做什么/不能做什么）→ Prompt 与 RAG 概念→AI 产品设计（对话/工作流/评测）。薪资 20-40K，传统产品经理转型路径最短。
## 提示词工程师
技能主线：Prompt 模式（角色/少样本/思维链）→ 评测方法 → 场景落地。独立岗位在收敛，更常见为复合技能（产品/运营 + Prompt 能力），单价项目 500-2000 元/篇或并入其他岗位。
