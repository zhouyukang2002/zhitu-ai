## Java 后端工程师岗位画像
岗位职责：设计并实现服务端业务逻辑与 API、数据库建模与调优、参与系统架构演进。技能主线（按学习顺序）：JavaSE 基础 → 集合/泛型/多线程 → MySQL 与 SQL → MyBatis 持久层 → Servlet/Spring MVC → Spring/SpringBoot → Redis → 消息队列 → 微服务与项目实战。面试高频考点集中在集合原理、并发、MySQL 索引与事务、Spring 机制四大块。
薪酬参考：一线城市初级 10-15K，3 年经验 18-30K；二三线约为一线的 60-75%。
转型周期：零基础全职学习约 6-9 个月，在职转型约 10-14 个月。

## 测试工程师转型 Java 后端路径
优势起点：已具备 Linux 基础、SQL 能力、HTTP 协议理解与业务敏感度，可跳过通用基础直接补语言栈。推荐路径（约 5-7 个月）：《Java 编程入门》→《Java 核心技术进阶》→《JDBC 与 MyBatis》→《Java Web 开发》→《Spring/SpringBoot》→《Redis》→ 项目实战 + 面试冲刺。
关键提示：测试背景的差异化竞争力在质量意识——转型后主打"会写代码更会保障质量"，自动化测试经验在 CI/CD 与工程化岗位是加分项。简历重点讲清"为什么转"（如对业务逻辑与代码质量的兴趣），并准备 2 个可深挖的项目。

## 后端工程师补充 AI 应用能力路径
大模型时代后端的增量方向：在已有 Java/Spring 基础上补 Python AI 开发 → 大模型 API 与 Prompt 工程 → RAG 检索增强 → Agent 开发。该路径不要求转岗，而是让后端工程师能落地"AI + 业务"场景（智能客服、知识库问答），是当前溢价最高的复合技能组合。对应课程：《Python AI 开发基础》《大模型应用开发入门》《RAG 检索增强实战》《AI Agent 开发实战》。
