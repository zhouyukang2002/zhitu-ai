## 课程介绍
Java 后端面试与实战的分水岭课程。深入讲解 HashMap 与 ConcurrentHashMap 的底层结构、ArrayList 与 LinkedList 的取舍、泛型擦除、IO 流体系与线程池实战，每个专题配 2 道企业级案例。学完能读懂大部分业务代码，并从容应对面试中的"集合与并发"高频考点。

【适合人群】学完 JavaSE 基础、想进阶后端开发的转行人群；准备跳槽面试的初级开发者。
【目标岗位】Java 后端工程师（进阶必修），也是大模型应用工程师（Java 方向）的语言底座。
【前置要求】掌握 JavaSE 基础与面向对象；建议先完成《Java 编程入门》。
【学习周期】每天 2 小时，约 4 周完成。

## 课程大纲
- 第 1 章 常用集合：ArrayList/LinkedList/HashMap（8h）
- 第 2 章 HashMap 底层原理与扩容机制（6h）
- 第 3 章 泛型与类型擦除（5h）
- 第 4 章 IO 流与文件读写（6h）
- 第 5 章 多线程基础：Thread 与线程安全（7h）
- 第 6 章 线程池原理与实战参数（7h）
- 第 7 章 ConcurrentHashMap 与并发容器（5h）
- 第 8 章 综合实战：多线程日志采集器（4h）
