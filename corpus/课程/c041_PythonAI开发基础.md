## 课程介绍
AI 应用开发的起点：配置 Python 与虚拟环境、掌握 NumPy 基础、学会调用大模型 API 与管理密钥，搭建可持续迭代的 AI 项目工程。
【适合人群】有 Python 基础、进入 AI 方向的开发者。
【目标岗位】大模型应用工程师（起点）。
【学习周期】每天 1.5 小时，约 2 周完成。
## 课程大纲
- 第 1 章 环境与虚拟环境（3h）- 第 2 章 NumPy 与数据表示（5h）- 第 3 章 首次调用大模型 API（5h）- 第 4 章 密钥管理与成本意识（3h）- 第 5 章 工程结构与调试（4h）
