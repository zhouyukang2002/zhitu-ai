## 课程介绍
从取数进阶到数仓。讲透窗口函数进阶与复杂查询优化、数仓分层（ODS/DWD/DWS/ADS）、维度建模与 Hive SQL 实战，理解"指标为什么从这里来"，打通分析师与数据工程师的语言。

【适合人群】有 SQL 基础、想进阶数仓/BI 方向的分析师与工程师。
【目标岗位】数据仓库工程师、高级数据分析师。
【学习周期】每天 2 小时，约 3 周完成。

## 课程大纲
- 第 1 章 窗口函数进阶与复杂查询（6h）
- 第 2 章 数仓分层与命名规范（5h）
- 第 3 章 维度建模：事实与维度（6h）
- 第 4 章 Hive SQL 与执行原理（6h）
- 第 5 章 数据倾斜定位与治理（5h）
- 第 6 章 指标口径管理与调度（3h）
- 第 7 章 综合实战：订单宽表建模（3h）
