## 课程介绍
前端第一课。从网页的结构（HTML）、表现（CSS）与行为（JavaScript）三层讲起，掌握语义化标签、盒模型、Flex 弹性布局与原生 JS 的 DOM 操作，最终独立还原一个企业官网页面。零基础友好，全部案例浏览器直接运行。

【适合人群】零基础转行前端、需要看懂前端的测试与产品同学。
【目标岗位】前端开发工程师（第一站）。
【学习周期】每天 2 小时，约 3 周完成。

## 课程大纲
- 第 1 章 网页三层结构与开发工具（3h）
- 第 2 章 HTML 语义化标签与表单（6h）
- 第 3 章 CSS 选择器与盒模型（6h）
- 第 4 章 Flex 弹性布局与响应式（7h）
- 第 5 章 JavaScript 变量、函数与流程控制（7h）
- 第 6 章 DOM 操作与事件（7h）
- 第 7 章 综合实战：企业官网还原（4h）
