## 课程介绍
后端与运维的公共地基。掌握日常高频 Linux 命令、文件权限体系、TCP/IP 与 HTTP 网络基础，学会部署一个服务并独立排查"连不上、起不来、看不到"三类问题。

【适合人群】开发与测试方向学员，运维入门者。
【目标岗位】运维/DevOps 工程师（起点）、所有开发岗的必备底座。
【学习周期】每天 1.5 小时，约 2 周完成。

## 课程大纲
- 第 1 章 Linux 入门与常用命令（5h）
- 第 2 章 文件系统与权限（4h）
- 第 3 章 进程与服务管理（4h）
- 第 4 章 网络基础：TCP/IP 与 HTTP（5h）
- 第 5 章 服务部署与日志排查（4h）
- 第 6 章 综合实战：从零部署一个 Web 服务（2h）
