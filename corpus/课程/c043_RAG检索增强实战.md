## 课程介绍
企业级 AI 应用的标配架构。讲透 Embedding 语义原理、BM25+向量+RRF 混合检索、分块策略与引用溯源，重点训练"召回不准怎么排查"的系统方法，用企业知识库问答案例贯穿。

【适合人群】有 Python 与大模型 API 基础的开发者。
【目标岗位】大模型应用工程师（核心技能）。
【前置要求】大模型 API 基础；了解 ES 更佳。
【学习周期】每天 2 小时，约 3 周完成。

## 课程大纲
- 第 1 章 RAG 架构：为什么需要检索增强（4h）
- 第 2 章 Embedding 原理与向量化（5h）
- 第 3 章 分块策略与语料治理（5h）
- 第 4 章 混合检索：BM25+向量+RRF（7h）
- 第 5 章 引用溯源与忠实性约束（4h）
- 第 6 章 评测与调优：召回率与忠实度（6h）
- 第 7 章 综合实战：企业知识库问答（3h）
