## 课程介绍
并发是后端面试的深水区。从 Java 内存模型与三大特性讲起，覆盖 synchronized 锁升级、AQS 框架、线程池实战参数、并发容器与并发工具类（CountDownLatch/Semaphore），每个知识点配"错误示范→正确实现"对照实验。

【适合人群】有多线程基础、想系统性掌握并发编程的开发者。
【目标岗位】Java 后端工程师（高级面试核心板块）。
【前置要求】JavaSE 基础 + 集合框架。
【学习周期】每天 2 小时，约 4 周完成。

## 课程大纲
- 第 1 章 Java 内存模型：可见性/原子性/有序性（6h）
- 第 2 章 synchronized 与锁升级（6h）
- 第 3 章 volatile 与 CAS 原理（5h）
- 第 4 章 AQS 与 ReentrantLock（7h）
- 第 5 章 线程池深度实战（6h）
- 第 6 章 并发容器与并发工具类（6h）
- 第 7 章 综合实战：高并发计数与限流器（6h）
