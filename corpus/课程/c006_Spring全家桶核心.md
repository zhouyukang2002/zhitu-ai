## 课程介绍
Java 后端面试与进阶的核心课。从手写简易 IoC 容器理解控制反转的本质，到 AOP 动态代理、Bean 生命周期、循环依赖三级缓存，再到声明式事务的传播行为与失效场景——每个原理都配"手写简化版"练习，面试能讲原理、开发能用得对。

【适合人群】会用 SpringBoot 但讲不清原理的开发者；准备中高级面试的后端工程师。
【目标岗位】Java 后端工程师（面试必考），也是全栈工程师服务端进阶课。
【前置要求】Spring MVC 基础 + MyBatis（对应《Java Web 开发》《JDBC 与 MyBatis 持久层实战》）。
【学习周期】每天 2 小时，约 4 周完成。

## 课程大纲
- 第 1 章 IoC 思想与手写简易容器（6h）
- 第 2 章 Bean 定义、作用域与生命周期（7h）
- 第 3 章 依赖注入方式与循环依赖三级缓存（6h）
- 第 4 章 AOP 原理：动态代理与切面编程（7h）
- 第 5 章 常用注解原理：@Component/@Autowired/@Value（6h）
- 第 6 章 声明式事务：传播行为与失效场景（7h）
- 第 7 章 事件机制与扩展点（3h）
- 第 8 章 综合实战：手写简化版 Spring 框架（4h）
