## 课程介绍
理解 Web 后端"请求进来、响应出去"的完整链路。先讲 HTTP 协议与 Servlet 生命周期，理解 Spring MVC 帮你省掉了什么，再系统掌握控制器、参数绑定、拦截器与 RESTful 接口设计，最终交付一套前后端分离的用户管理 API。

【适合人群】学完 JavaSE 与数据库、准备进入 Web 开发的转行人群。
【目标岗位】Java 后端工程师（核心必修），全栈工程师的服务端部分。
【前置要求】JavaSE 基础 + SQL 基础；建议同步学习 MyBatis。
【学习周期】每天 2 小时，约 3 周完成。

## 课程大纲
- 第 1 章 HTTP 协议与请求响应模型（4h）
- 第 2 章 Servlet 生命周期与容器（5h）
- 第 3 章 Spring MVC：控制器与参数绑定（7h）
- 第 4 章 RESTful API 设计规范（5h）
- 第 5 章 会话与 Cookie、登录鉴权（5h）
- 第 6 章 拦截器与全局异常处理（4h）
- 第 7 章 综合实战：用户管理 API（前后端分离）（4h）
