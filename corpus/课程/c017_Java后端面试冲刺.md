## 课程介绍
知识都有，但答不出彩？本课把 Java 后端面试的高频题按"考官意图"重新组织：每道题讲清"面试官想听到什么、加分点在哪、常见翻坑"，配合项目表达模板（STAR 法则）与场景设计题拆解（秒杀/短链/排行榜），把已有知识转化为 offer。

【适合人群】完成 Java 后端主线课程、即将进入面试期的学员。
【目标岗位】Java 后端工程师（面试直接命中）。
【前置要求】完成集合/并发/MySQL/Redis/Spring 主线课程。
【学习周期】每天 1.5 小时，约 2 周完成。

## 课程大纲
- 第 1 章 简历与项目表达：STAR 法则与深挖预案（4h）
- 第 2 章 集合与并发高频题精讲（6h）
- 第 3 章 MySQL 高频题精讲（5h）
- 第 4 章 Redis 高频题精讲（5h）
- 第 5 章 场景设计题拆解：秒杀/短链/排行榜（6h）
- 第 6 章 反问环节与薪资谈判（4h）
