## 课程介绍
连接 Java 与数据库的桥梁课。先用手写 JDBC 理解连接、语句与结果集的本质，再过渡到企业主流框架 MyBatis，掌握 Mapper 接口、动态 SQL 与连接池配置，最终完成图书管理系统的持久层改造。学完即满足后端岗位对"持久层开发"的硬性要求。

【适合人群】已掌握 Java 基础与 SQL 基础的转行人群。
【目标岗位】Java 后端工程师（必学），同样适用于测试开发岗位。
【前置要求】JavaSE 基础 + SQL 基础（对应《Java 编程入门》《MySQL 数据库从入门到索引调优》）。
【学习周期】每天 1.5 小时，约 2 周完成。

## 课程大纲
- 第 1 章 JDBC 原生开发：连接与事务（5h）
- 第 2 章 连接池原理与 Druid 实战（4h）
- 第 3 章 MyBatis 入门：Mapper 与映射（6h）
- 第 4 章 动态 SQL：if/where/foreach（5h）
- 第 5 章 关联映射与延迟加载（4h）
- 第 6 章 综合实战：图书管理系统持久层（4h）
