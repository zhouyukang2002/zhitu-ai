## 课程介绍
AI 应用第一课。讲透 messages 角色模型、温度与参数、Prompt 核心模式（角色设定/少样本/思维链/结构化输出约束），以及成本与稳定性工程化，完成一个可对话、可抽取结构的命令行助手。

【适合人群】有 Python 基础、进入大模型应用方向的开发者与产品经理。
【目标岗位】大模型应用工程师（起点）、AI 产品经理、提示词工程师。
【学习周期】每天 1.5 小时，约 2.5 周完成。

## 课程大纲
- 第 1 章 大模型能力边界与选型（4h）
- 第 2 章 API 角色模型与参数调优（5h）
- 第 3 章 Prompt 工程核心模式（7h）
- 第 4 章 结构化输出与校验（5h）
- 第 5 章 多轮对话与上下文管理（5h）
- 第 6 章 综合实战：命令行智能助手（4h）
