## 课程介绍
零基础跨行转码的第一门课。从安装 JDK 与 IDEA 开始，手把手带你写出第一个 Java 程序，系统掌握变量、流程控制、方法、数组与面向对象三大特性（封装、继承、多态），课程以"学生成绩管理系统"贯穿实战，学完即可独立编写控制台项目。

【适合人群】零基础转行人群、在校非计算机专业学生、想补齐编程基础的其他岗位从业者。
【目标岗位】Java 后端工程师（第一站），也为全栈工程师、测试工程师转开发打下语言基础。
【学习周期】每天 2 小时，约 3 周完成；无需任何编程经验。

## 课程大纲
- 第 1 章 开发环境搭建：JDK 安装与 IDEA 实战（3h）
- 第 2 章 变量、数据类型与运算符（5h）
- 第 3 章 流程控制：if/switch/for/while（6h）
- 第 4 章 方法与数组（6h）
- 第 5 章 面向对象：类与对象、封装（7h）
- 第 6 章 继承与多态、抽象类与接口（8h）
- 第 7 章 异常处理入门（3h）
- 第 8 章 综合实战：学生成绩管理系统（4h）
