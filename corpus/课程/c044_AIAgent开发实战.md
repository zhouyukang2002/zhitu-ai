## 课程介绍
从"对话"到"干活"。讲透 Function Calling 的工具选择机制、MCP 协议的工具服务化封装、Agent 编排模式（固定流水线 vs 动态计划 vs 自主循环）与工具级权限设计，实战把业务系统能力安全地交给 Agent。

【适合人群】有 RAG 基础、想让 AI 接入真实业务的开发者。
【目标岗位】大模型应用工程师（核心差异化技能）。
【学习周期】每天 2 小时，约 3.5 周完成。

## 课程大纲
- 第 1 章 Agent 是什么：感知-决策-行动循环（4h）
- 第 2 章 Function Calling 原理与实战（6h）
- 第 3 章 MCP 协议：工具服务化与标准接入（6h）
- 第 4 章 Agent 编排模式与选型（6h）
- 第 5 章 工具权限与安全设计（5h）
- 第 6 章 多智能体协作（5h）
- 第 7 章 综合实战：课程助教 Agent（6h）
